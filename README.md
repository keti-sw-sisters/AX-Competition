## 1. 과제 개요

### 문제

충청권 약 **500만 명**의 상수원인 대청댐은 매년 여름 **유해남조류(녹조)** 문제에 직면한다.  
현행 조류경보제는 **현장 채수 → 현미경 계수 → 경보 발령**의 순서를 따른다.

```
[현재] 녹조 이미 발생 ──▶ 측정 ──▶ 경보 발령 ──▶ 긴급 대응
                                           ↑
                                    이미 늦은 상태
```

이 방식의 핵심 한계는 **사후 대응**이라는 점이다.  
경보가 발령될 때는 이미 조류가 번성해 취수 제한, 정수 비용 급증, 시민 불편이 현실화된 이후다.

### 목표

```
[목표] 환경 조건 감지 ──▶ AI 예측 ──▶ 7~14일 전 경보 ──▶ 선제 대응
                                           ↑
                                    시간 여유 확보
```


| 목표        | 내용                                                                        |
| --------- | ------------------------------------------------------------------------- |
| **예측**    | 조류경보 발령 시점을 7일(T+7) / 14일(T+14) 전 예측                                      |
| **설명**    | 발생 메커니즘의 주요 인자를 데이터로 정량 규명                                                |
| **운영 지원** | 방류량·체류시간 등 통제 가능 변수 조작 시 위험 변화 시뮬레이션                                      |
| **대시보드**  | 수자원공사 (운영) 실무에서 활용 가능한 실시간 의사결정 지원 화면 (추후 같은 데이터 확보 시 타 댐 운영 및 관리로 확장 가능) |


### 조류경보제 발령 기준


| 단계     | 세포 수 기준       | 발령 조건    | 주요 조치            |
| ------ | ------------- | -------- | ---------------- |
| 미발령    | 1,000 미만      | —        | 정기 모니터링          |
| **관심** | **1,000 이상**  | 2회 연속 초과 | 모니터링 강화, 관계기관 통보 |
| **경계** | **10,000 이상** | 2회 연속 초과 | 취수 제한 검토, 정수 강화  |
| 대발생    | 1,000,000 이상  | 1회 초과    | 긴급 대응, 취수 중단     |

## 4. 1단계 — EDA: 데이터 탐색

*파일: `data_eda.ipynb`*

### 4-1. 계절성 — 발령은 여름에 집중된다

```
월별 발령 비율
1월  ░░░░░░░░░░  ~0%
2월  ░░░░░░░░░░  ~0%
3월  ░░░░░░░░░░  ~1%
4월  ██░░░░░░░░  ~5%
5월  ████░░░░░░  ~10%
6월  ██████░░░░  ~18%
7월  ████████░░  ~35%   ← 최고
8월  ████████░░  ~38%   ← 최고
9월  ██████░░░░  ~25%
10월 ████░░░░░░  ~8%
11월 ██░░░░░░░░  ~2%
12월 ░░░░░░░░░░  ~0%
```

**인사이트**: 모니터링 자원은 7~~9월에 집중해야한다. 비수기 (1~~3월) 발령 사례는 이상 기온 연도와 겹친다.

### 4-2. 연도별 패턴 — 발생 시점이 앞당겨지고 있다

연도별 오버레이(Day-of-Year) 분석 결과:

- **이상 고온 연도**에 남조류 발생이 눈에 띄게 이른 시기부터 시작
- 최근 5년간 발생 개시 시점이 평균 **7~10일 앞당겨진** 경향 확인
- 기후변화로 인한 구조적 위험 증가를 시사

### 4-3. 남조류 농도의 비선형성

원시 세포 수(cells/mL)는 **수천에서 수백만까지** 분포 범위가 극단적으로 넓다.  
로그 변환 `log1p(total_cyano)`를 적용하면 정규분포에 가까워지고 이상값 영향이 줄어든다.  
이 변환값을 분석 전체에서 **핵심 연속 타겟**으로 사용한다.

### 4-4. 발령과 강한 상관을 보이는 변수 (상위 5위)


| 순위  | 변수             | 발령 시 특성                                |
| --- | -------------- | -------------------------------------- |
| 1   | **수온(℃)**      | 미발령 평균 ~12°C vs 발령 평균 ~25°C — 가장 큰 분리력 |
| 2   | **Chl-a(㎎/㎥)** | 발령 시 2~5배 높음 — 조류 현존량의 대리 지표           |
| 3   | **합계 일사량**     | 발령 시 유의하게 높음 — 광합성 에너지 공급              |
| 4   | **저수율(%)**     | 발령 시 낮아지는 경향 — 체류시간과 반비례               |
| 5   | **DO(㎎/L)**    | 발령 시 감소 — 대량 광합성·호흡으로 용존산소 소모          |


### 4-5. 기초 모델 4종 비교 (EDA 단계)


| 모델                    | ROC-AUC | F1(발령) | Recall(발령) |
| --------------------- | ------- | ------ | ---------- |
| Logistic Regression   | 0.9055  | 0.8666 | 0.8178     |
| Decision Tree         | 0.9015  | 0.8588 | 0.7793     |
| Random Forest         | 0.9894  | 0.8485 | 0.751      |
| **Gradient Boosting** | 0.9839  | 0.7766 | 0.6385     |


> EDA 단계의 GBM은 피처 공학 없이 원본 변수만 사용한 기준선(Baseline) 성능이다.

### 4-6. SHAP 분석 (Ex AI)

Random Forest 기준 SHAP 중요도 Top-5:

1. **수온(℃)** — 가장 강력한 단일 예측 변수. 25°C 초과 시 기여도 급등
2. **Chl-a** — 현재 조류 상태가 미래 급증 예측에 결정적
3. **합계 일사량** — 광합성 에너지 누적 효과
4. **저수율(%)** — 낮을수록 발령 위험 상승 (정체수역 형성)
5. **평균기온** / **수온_roll14** — 단기 수온보다 **2주 누적 고온**이 더 강력한 신호

**SHAP 해석 규칙**: 빨간 점(고값)이 오른쪽(발령 방향)으로 모이면 → "해당 변수 높을수록 위험 증가"

## 5. 2단계 — 가설 검증: 왜 발생하는가

*파일: `algae_analysis.ipynb` — Section 2*

EDA에서 "무엇이 보이는가"를 확인했다면, 이 단계에서는 **왜 발생하는가**라는 메커니즘 가설을 통계적으로 검증한다.

### H1: 열 축적 임계 가설 ✅ 확인

> **"단일 수온보다 CHD(연속 고온일수)가 발령 전환의 더 강력한 예측 변수이다"**

- **검정**: Mann-Whitney U 검정 — 발령 전환 시점 vs 미발령 기간의 CHD 비교
- **결과**: 발령 전환 시점에서 CHD가 유의하게 높음 (p < 0.01)
- **의미**: 수온이 25°C를 **며칠 연속** 넘었는지가 단일 수온값보다 발령을 더 잘 예측한다. 남조류는 고온이 **지속**될 때 번성한다.

### H2: 체류시간 × 영양 상태 복합 트리거 가설 ✅ 확인

> **"HRT(체류시간) 증가 × Chl-a 상승의 복합 조건이 경보 발령을 가장 강력하게 예측한다"**

- **검정**: 2×2 분할표 + 상호작용 항 회귀
- **결과**: HRT 높음 + Chl-a 높음 조건에서 발령 비율이 다른 조합 대비 **3~5배** 높음
- **의미**: 물이 오래 머물면서(HRT↑) 영양분(Chl-a↑)도 많을 때 폭발적 증식이 시작된다. **방류량을 늘려 HRT를 줄이는 것이 가장 직접적인 통제 수단이다.**

### H3: 강우 후 영양염 지연 공급 가설 ✅ 확인

> **"장기 무강우(CDD≥14일) 후 첫 강우 이벤트 7~14일 후에 조류 급증 위험이 높아진다"**

- **검정**: 이벤트 중심 분석(Event Study) — 강우 펄스 기준 -7일 ~ +21일 log_cyano 평균 추적
- **결과**: 강우 펄스 **7~14일 후** log_cyano가 유의하게 상승
- **의미**: 장마 후 토양의 질소·인이 한꺼번에 유입되고, 7~14일 후 남조류가 이를 흡수해 급증한다. 강우 이벤트가 **조기 경보 트리거**로 활용될 수 있다.

### H4: 지점 간 공간 전파 가설 ✅ 확인

> **"회남(상류)의 조류 수준이 문의(하류) 7~14일 후 조류의 선행 지표이다"**

- **검정**: 교차상관함수(CCF) — 회남 log_cyano vs 문의 log_cyano의 시차별 상관
- **결과**: 시차 7~~14일에서 CCF 피크 확인 (r≈0.45~~0.60)
- **의미**: 상류(회남)에서 먼저 발생한 조류가 7~14일 후 하류(문의)로 도달한다. **회남 모니터링 강화로 문의 발령을 사전에 예측**할 수 있다.

### H5: 체제 전환(Regime Shift) 가설 ✅ 확인

> **"조류 급증 전 분산·자기상관 증가라는 Early Warning Signal이 발령보다 7~14일 선행한다"**

- **검정**: 슬라이딩 윈도우(30일) 롤링 분산·AR(1) 자기상관 계산 후 발령 이전 추이 확인
- **결과**: 발령 시점보다 평균 **7~12일 전**에 분산과 AR(1)이 동시 상승
  - **AR(1) 자기상관 증가**: 오늘이 높으면 내일도 높고(혹은 낮으면 내일도 낮은) **“관성이 커진다”**는 뜻. 즉, 시스템이 충격을 받으면 **원래 상태로 빨리 복원되지 못하고 느리게 회복**한다.
- **의미**: 시스템이 **안정 상태 → 불안정 상태**로 전환되기 직전, 요동이 커지는 보편적 패턴(Critical Slowing Down)이 남조류 급증에도 적용된다.
  - **Critical Slowing Down(임계 지연)**: 안정 → 불안정으로 넘어가기 직전엔, 작은 변화에도 **회복이 느려지고 요동이 커지는** 보편적 현상. (그래서 분산↑ + 자기상관↑가 같이 뜨는 걸 전조로 봄)

### 가설 검증 요약


| 가설                 | 결과   | 핵심 인사이트                  |
| ------------------ | ---- | ------------------------ |
| H1: 열 축적 (CHD)     | ✅ 확인 | 수온 지속성이 단순 수온보다 중요       |
| H2: HRT × Chl-a 복합 | ✅ 확인 | 두 조건 동시 충족 시 위험 3~5배     |
| H3: 강우 펄스          | ✅ 확인 | 강우 후 7~14일이 급증 타이밍       |
| H4: 공간 전파 (회남→문의)  | ✅ 확인 | 상류 7~14일 선행 신호 활용 가능     |
| H5: 체제 전환 EWS      | ✅ 확인 | 분산·AR1 상승이 발령보다 7~12일 선행 |


**5가지 가설 모두 통계적으로 확인됨** → 이를 기반으로 피처엔지니어링과 모델링 설계

## 6. 3단계 — Feature Engineering: 메커니즘을 숫자로

*파일: `algae_analysis.ipynb` — Section 1*

확인된 메커니즘을 모델이 학습할 수 있는 **숫자 피처**로 변환한다.

### 환경 메커니즘 피처


| 피처                   | 계산 방법                                 | 근거 가설 | 직관적 의미           |
| -------------------- | ------------------------------------- | ----- | ---------------- |
| **CHD**              | 수온≥25°C 연속 일수                         | H1    | 연속 폭염이 며칠째인지     |
| **TAI_7**            | Σ max(기온−20, 0) · 7일                  | H1    | 1주일간 누적 열 부하     |
| **HRT_est**          | 저수량(㎥) / 유입량(㎥/일)                     | H2    | 물이 댐에 머무는 평균 일수  |
| **IO_imbalance**     | (유입량 − 방류량) / 유입량                     | H2    | 수위 상승 추세 지표      |
| **CDD**              | 강우량<1mm 연속 일수                         | H3    | 건조 기간이 며칠째인지     |
| **rain_pulse**       | CDD≥14 직후 강우 이벤트                      | H3    | 영양염 유입 트리거 발생 여부 |
| **days_since_pulse** | 마지막 강우 펄스 후 경과일                       | H3    | 유입된 영양염이 얼마나 됐는지 |
| **strat_proxy**      | 수온 × 일사량 / (풍속+0.1)                   | H2    | 열적 성층 강도 (교란 저항) |
| **BGI**              | (수온−20)/10 × 일사량/solar_max × 1/(탁도+1) | H1+H2 | 성장 조건 종합 지수      |
| **회남_log_lag7**      | 회남 지점 log_cyano를 7일 shift             | H4    | 상류 선행 신호         |
| **ews_var**          | log_cyano 30일 롤링 분산                   | H5    | 조기 경보 신호         |


### 시계열 파생 피처 (Lag/Rolling)

남조류는 단일 시점이 아닌 **며칠간의 누적 조건**에 반응한다.

```
수온_lag7     = 7일 전 수온        (단기 선행)
수온_roll7    = 직전 7일 평균 수온  (단기 누적)
수온_roll14   = 직전 14일 평균 수온 (중기 누적)
Chl-a_lag14  = 14일 전 Chl-a      (선행 조류 상태)
```

> **중요**: `total_cyano`, `microcystis` 등 **남조류 세포 수 변수는 모든 모델 입력에서 제외**  
> 이유: 세포 수는 발령 기준의 직접 근거 — 입력에 포함하면 미래를 미리 아는 것과 같은 **데이터 누수(Data Leakage)**가 발생한다.

## 7. 4단계 — 최적 모델링: 어떻게 예측하는가

*파일: `algae_analysis.ipynb` — Section 3*

### 전략 선택 배경: 왜 단순 분류가 아닌가

경계(4.8%) 같은 극소수 클래스를 단순 분류로 예측하면 모델이 "전부 미발령"으로 분류해버린다.  
이를 해결하기 위해 두 가지 전략을 제안:

### 전략 A — 위험 점수 회귀 (Risk Score Regression)

```
입력 피처 → GBM → 예측값: log1p(total_cyano) → 위험 점수(연속값)
                                                         ↓
                                              임계값으로 경보 단계 환산
```

- **타겟**: `log1p(total_cyano)` — 연속값으로 예측 후 임계값 변환 
- **장점**: 희귀 이벤트 불균형 문제 없음, "얼마나 위험한가"를 연속적으로 표현 (“단계”가 아니라 **연속값 위험 점수/** “지금 위험이 얼마나 큰지”를 **숫자로 직관적으로** 보여줄 수 있음)
- **모델 비교**:


| 모델                   | ROC-AUC | Recall(발령) | 비고        |
| -------------------- | ------- | ---------- | --------- |
| **Ridge Regression** | 0.976   | 0.704      | **최종 선정** |
| Random Forest (Reg)  | 0.965   | 0.524      | 비선형       |
| GBM Regressor        | 0.972   | 0.569      | **빠름**    |


### 전략 B — 계층적 이진 분류 (Hierarchical Classification)

```
[Level 1] GBM: 발령 여부 예측 (미발령 vs 발령)
                      │
          [Level 2 — 발령 시에만] GBM: 관심 vs 경계 분류
```

- **장점**: 미발령이 압도적인 불균형 속에서도 경계 단계 탐지 집중 가능
- **ROC-AUC**: Level 1 ~0.96, Level 2 ~0.65

### 최종 선택: GBM Regressor (Risk Score) -> RIDGE로 수정

GBM Regressor를 최종 모델로 선정한 이유:

1. ROC-AUC 최고 (발령/미발령 이진 전환 기준)
2. 연속 위험 점수 → 운영팀이 임계값을 유연하게 조정 가능
3. SHAP 해석 완전 지원

모델 저장: `algae_model_t7.pkl`

### 비용 최적 임계값 설정

> 미발령 오류(경보 놓침, FN)는 취수 오염 등 **사회·환경적 피해 = 6배 비용 (***근거!!)**  
> 과발령 오류(불필요 취수 제한, FP)는 **행정 비용 = 1배**

**FN:FP = 6:1** 비용 비율을 적용한 비용 최소화 임계값: **0.25~0.30**  
(표준 0.5 임계값 대비 Recall이 약 15%p 향상)

### 선행 예측 (Lead-time) 성능


| 예측 시점          | ROC-AUC | Recall(발령) | 실용적 의미                  |
| -------------- | ------- | ---------- | ----------------------- |
| T+0 (당일)       | 0.9624  | 0.8030     | 현재 상태 확인                |
| **T+7 (7일 후)** | 0.9674  | 0.8089     | **실무 권장 — 방류 계획 조정 가능** |
| T+14 (14일 후)   | 0.9399  | 0.7393     | 장기 계획 수립 참고용            |


**→ T+7 예측 프레임을 실무 운영 기준으로 권장**

```
├── algae_model_t7.pkl          ← 최종 예측 모델 (algae_analysis 실행 후 생성)
├── dashboard_mockup.png        ← 대시보드 화면 목업 이미지
└── README.md                   ← 이 문서
```

### 실행 순서

```
1. Code_File.ipynb  (선택 — 전처리 과정 확인)
        ↓
2. data_eda.ipynb             (EDA + 기초 모델링)
        ↓
3. algae_analysis.ipynb       (가설검증 + 최적모델 + 시뮬레이션)
        ↓   algae_model_t7.pkl 생성
4. streamlit run dashboard_app.py
```
